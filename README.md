# ระบบบริหารการใช้รถของราชการ (Driver Management System)
### วิทยาลัยพยาบาลบรมราชชนนี สวรรค์ประชารักษ์ นครสวรรค์

ระบบเว็บแอปพลิเคชันบริหารจัดการและกำกับติดตามการใช้รถราชการ พัฒนาขึ้นเพื่อเพิ่มประสิทธิภาพในการกำกับดูแล การจัดสรรยานพาหนะ และการตรวจสอบสถานะพนักงานขับรถราชการ (พขร.) ภายในวิทยาลัยพยาบาลบรมราชชนนี สวรรค์ประชารักษ์ นครสวรรค์

## 🌟 ฟังก์ชันหลักของระบบ (Key Features)

### 🚗 ศูนย์สถานะสด พขร. & เวรประจำสัปดาห์ (Live Driver Dispatch)
* ตรวจสอบสถานะความพร้อมของ พขร. ประจำวัน (พร้อมปฏิบัติงาน / ออกปฏิบัติงาน / ลา)
* แสดงแถบเวรหลักประจำสัปดาห์ (รอบ 7 วัน เสาร์-ศุกร์) แบบ Real-time
* ตรวจสอบรายละเอียดภารกิจที่กำลังเดินทางอยู่แบบทันที

### 📊 ปฏิทิน 3 เลเยอร์ & รายงานสถิติ (Calendar & Analytics)
* **Interactive Calendar View**: ปฏิทินแสดงภารกิจการเดินรถ ตารางเวร และวันลา แยกสี พขร. ชัดเจน
* **สถิติ 4 ประเภทงาน**: สรุปยอดเที่ยววิ่งและกราฟเปรียบเทียบตามประเภทงาน (นิเทศ, บริหาร, ประชุม, นำส่ง)
* **ตัวกรองประวัติย้อนหลัง**: ค้นหาและดูสถิติย้อนหลังได้ทุกงวดเดือน

### 📝 บันทึกและจัดการข้อมูลการใช้รถ (Zero-Typing Admin Form)
* **Mobile-First UI**: ออกแบบพอดีจอมือถือ พร้อมปุ่มลัด 1-Tap ไม่ต้องพิมพ์
* **Smart Conflict Checking**: ระบบตรวจจับและป้องกันการจัด พขร. ซ้ำซ้อนกับคิวงานอื่น
* **Audit Trail**: บันทึกประวัติการแก้ไขและลบข้อมูลอย่างโปร่งใส

## 🔒 การควบคุมสิทธิ์และความปลอดภัย (Access Control)
* **ระบบจำกัดสิทธิ์ภายในองค์กร**: อนุญาตให้เข้าใช้งานเฉพาะบุคลากรที่ผ่านการยืนยันตัวตนด้วยบัญชี Google Workspace ของวิทยาลัย (@bcnsprnw.ac.th)
* **การแบ่งบทบาท (Role Separation)**:
  * **ผู้ดูแลระบบ (Admin)**: สิทธิ์ในการบันทึก แก้ไข ลบ และจัดตารางเวร
  * **ผู้ใช้งานทั่วไป (Viewer)**: สิทธิ์ในการดูข้อมูลปฏิทิน และตรวจสอบสถานะ พขร.
